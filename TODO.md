# Shramik Setu – To-do list

Use this checklist while finishing the project. Some items depend on the instructions in your department's project PDF, so check that document before submitting.

## Before coding
- [ ] Read the project guidelines and note every required deliverable.
- [ ] Write down the problem, intended users, inputs, and outputs.
- [ ] Confirm the skill categories and wage rules with the project guide.
- [ ] Draw a simple diagram showing how the files work together.

## Build the project
- [ ] Add worker registration and skill classification.
- [ ] Add attendance entry and date/time validation.
- [ ] Calculate shift hours and wages.
- [ ] Add the paid/unpaid status update.
- [ ] Connect the functions to the Tkinter screens.
- [ ] Check that saved CSV records are still there after restarting the app.

## Test it
- [ ] Try valid and invalid worker details.
- [ ] Check experience values around each skill-category boundary.
- [ ] Try valid and invalid dates and times.
- [ ] Check the wage calculation with a few examples.
- [ ] Try paying the same shift twice.
- [ ] Try selecting a shift ID that does not exist.
- [ ] Run `python -m unittest discover -s tests -v` and keep the output.

## Prepare the submission
- [ ] Finish the README and project report.
- [ ] Add screenshots, flowcharts, or pseudocode if the PDF asks for them.
- [ ] Match the report format to the department's template.
- [ ] Check that all required files are included.
- [ ] Push the project to GitHub and test the repository link.
